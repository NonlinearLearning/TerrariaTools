## 目录职责

- `目前设计/`：和当前源码一致的主题页，是修改代码时的默认入口。
- `历史设计/`：已经替代或只用于理解演变背景的设计稿。
- `优化历史/`：已执行的性能实验、测量和实施记录。
- `历史设计/2026-07-29至08-05-实施计划归档.md`：已清理计划的压缩结论和当前专题去向。
- `项目级-PRD-模板.md`：新项目或新阶段的模板，不描述当前实现。

## 更新规则

修改架构、规则边界、图契约或测试策略时，同批更新对应的 `目前设计/` 主题页。实施完成的方案从当前设计收口为事实，性能边界移入 `优化历史/`，未采纳方向移入 `历史设计/`。历史页不得反向成为当前实现依据。
